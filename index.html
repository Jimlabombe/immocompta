☁️ Google Drive

Connexion Google Drive

Une configuration unique de ~10 minutes est nécessaire. Faites les étapes ci-dessous une seule fois — ensuite c'est automatique.

1
Créer un projet Google Cloud

Allez sur console.cloud.google.com → Nouveau projet → nommez-le ImmoCompta → Créer.

2
Activer l'API Google Drive

Dans votre projet → menu gauche APIs et services → Bibliothèque → cherchez Google Drive API → cliquez Activer.

3
Créer un écran de consentement OAuth

APIs et services → Écran de consentement OAuth → choisissez Externe → remplissez le nom de l'application (ImmoCompta) et votre email → Enregistrer. Dans Utilisateurs test, ajoutez votre email Google.

4
Créer des identifiants OAuth

APIs et services → Identifiants → Créer des identifiants → ID client OAuth → Type : Application Web → Nom : ImmoCompta.

Dans Origines JavaScript autorisées, ajoutez :
null
(Pour les fichiers HTML locaux, "null" est l'origine correcte)

Cliquez Créer → copiez votre ID client.

5
Collez votre Client ID ici

Il ressemble à : 123456789-xxxxx.apps.googleusercontent.com
